# Guia de Operação Diária: Processamento de Vendas

Este é o fluxo operacional de rotina para a equipe da Avante Lingerie processar e enviar os pedidos do dia. Tudo acontece dentro do painel do **Bling**.

## 🔄 Fluxo Automático
Quando o cliente compra e paga no site, o sistema **automaticamente**:
- Muda o status para "Pago"
- Baixa o estoque do produto
- Envia o pedido para o Bling (já com o peso e transportadora configurados)

---

## 👩‍💻 O Seu Trabalho Diário (Apenas 3 Passos)

Sempre que iniciar o expediente, faça o seguinte no painel do Bling:

### 1. Emitir as Notas Fiscais (NF-e)
1. Vá no menu de **Vendas > Pedidos de Venda**.
2. Selecione os pedidos novos que estão pagos.
3. No botão lateral direito, clique em **"Gerar Notas Fiscais"**.
4. Autorize a emissão (A SEFAZ vai devolver todas autorizadas em segundos).

### 2. Comprar as Etiquetas (Gerar Remessa)
1. Agora, vá no menu **Vendas > Notas Fiscais**.
2. Selecione as notas fiscais que você acabou de gerar.
3. No menu superior ou lateral, clique em **"Gerar Remessas"** (Isso envia os dados para a Melhor Envio e compra as etiquetas automaticamente).

### 3. Imprimir Tudo
1. Acesse o menu de Integrações Logísticas (Melhor Envio) ou clique nas Remessas recém-geradas.
2. Selecione os pacotes e clique em **"Imprimir Etiquetas"**.
3. O Bling vai gerar um arquivo PDF único.
   - *A impressora térmica vai imprimir duas folhas sequenciais para cada pacote: A primeira é a Etiqueta dos Correios/Transportadora, e a segunda é a mini Nota Fiscal (DANFE Simplificada).*

## ✅ Fim!
Basta colar as duas folhas em cada pacote (sem precisar de plástico na DANFE, já que ela é térmica) e despachar!
