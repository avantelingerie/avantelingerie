## 1. A Lógica do Modelo "Chave na Mão" (Turnkey Funnel)

O Pedro Guimarães disponibiliza para os alunos uma infraestrutura pronta para faturar no perpétuo sem precisar criar o produto do zero:

* **O Produto Validado:** **Operação Resgate** (Nicho de Renda Extra com ticket de R$ 67,00).
* **Modelo de Comissionamento:** **100% de comissão na Hotmart** (configurado em 99% na plataforma para retenção de impostos na fonte pelo autor, repassando **R$ 58,78 líquido** por venda para o afiliado + order bumps e upsells).
* **Vantagem Competitiva:** O afiliado utiliza a autoridade, a imagem, os vídeos de vendas (VSL) e as provas sociais do Pedro Guimarães, recebendo todo o lucro líquido do funil.
